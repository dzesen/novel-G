# Novel-G 使用指南

本指南介绍日常创作入口。安装和升级见[源码包说明](source-release.zh-CN.md)，遇到问题见[排错指南](troubleshooting.zh-CN.md)。手动写作不需要模型 API Key。

## 创建第一本小说

首次进入工作台时创建管理员。管理员可以配置模型和备份，也可以在“设置 → 本机用户”创建其他作者账号。每个账号拥有自己的小说与浏览器草稿。

从书架新建小说，可以填写自己的故事方向、使用 AI 创意，或从审核后的酒馆卡开始。先确认题材、人物与故事方向，再整理世界资料和卷章结构。尚未确认的 AI 候选不会自动覆盖已有设定。

## 写作与修订

创建卷章后，在章节工作区编辑大纲与正文。界面支持自动保存、字数统计、本地草稿恢复和文本导出。需要 AI 协助时，可以显式使用续写、场景改写或检查工具，并在调用前确认费用范围。

单章生成默认“不审查”。完整草稿可由作者确认保存，不追加模型验收或状态核算；需要把本章变化用于后续章节时，再单独执行状态回填。保存正文、状态已回填和整书完成分别记录。

选择“保存前审查”时，按界面确认审查方式及用量。建议模式保留问题和证据供作者参考；严格模式可以阻止完成并要求处理。没有审查或审查尚未完成，不会被显示为审查通过。

## 自动成书

1. 确认故事方向、正式卷章结构和世界资料基线。处理待审核候选，并明确不适用的资料类别。
2. 在自动成书工作台选择整卷或整本范围，查看免费就绪预检。
3. 确认允许的生成与修复动作、调用次数、Token 和预算上限后启动。
4. 查看当前任务与章节进度。任务会在授权范围内推进，需要作者决策时暂停。

暂停后按当前任务给出的入口处理问题。世界资料问题在资料复核处解决；分场计划或输出风险在当前预检弹窗确认；正文和状态问题进入对应章节。处理完毕后重新检查，沿用仍有效的授权或创建新的授权。恢复不能静默扩大额度。

独立审查可以选择重点章节、指定章节、全部章节或不做常规审查。正文自动修复后的复核仍遵守该作业的原授权。任务记录可查看暂停原因、生成尝试、用量和审查证据。

## 世界资料与连续性

世界资料管理人物、地点、物品、规则、世界设定、势力与关系。AI 整理和导入先产生候选，由作者审核后新建、合并、恢复合并或跳过。自动成书只有在专门授权后，才可创建通过唯一性校验的全新资料；身份歧义仍需人工处理。

生成依据来自章细纲明确声明的正式资料。修改已有正文或设定后，留意状态完整性提示，按需重新回填状态或处理失效证据。

连续性与状态模块维护人物记忆、永久事实和伏笔。故事健康检查不调用模型，提供伏笔到期、角色缺席和篇幅偏离等提示；文风检查和卷级复盘需要作者显式发起模型调用。

## 酒馆角色卡与世界书

支持 SillyTavern Character Card V1/V2/V3 JSON、PNG 元数据，以及内嵌或独立世界书。先导入预览，检查分类、同名冲突与高风险字段，再逐项决定；可以导入已有小说，也可以从审核结果新建小说。

Character Card V2 JSON 导出目前通过按所有者隔离的后端下载端点提供，尚无专用导出界面。CHARX、角色卡 PNG 导出、头像和媒体附件导入、聊天记录转小说尚未支持。自由文本世界书无法保证自动分类准确，应在预览中复核。

## 未完成草稿与恢复

截断或缺少场景的正文会保留为未完成草稿。章节工作区提供可用草稿的显式续写、接受部分结果或丢弃操作。部分结果不能冒充完整章节推进状态链。

丢弃不会删除已经保存的章节正文。运行中断或用量未知时，先查看任务记录并处理未确认请求，不要把连续点击当作恢复方式。具体入口和排查顺序见[排错指南](troubleshooting.zh-CN.md)。

## 插图、备份与导出

封面、人物画像和场景插图是可选功能，需要配置兼容图像 API 或 ComfyUI 工作流并确认调用。插图不决定正文或整书是否完成。

章节编辑器可导出单章或整本小说文本。管理员可在“设置 → 备份与恢复”管理全库 JSON 备份和自动快照。数据库备份不包含本机配置与图片文件，迁移前应另外保留。恢复后需要重新登录并重新授权后续生成。

完整的支持范围见[使用范围与已知局限](known-limitations.zh-CN.md)。
