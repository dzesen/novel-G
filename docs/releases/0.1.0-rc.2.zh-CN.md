# Novel-G 0.1.0-rc.2

2026-09-11 私有源码评审候选，集中改善首次安装、失败重试与日常启动。安装和升级见[源码包说明](../source-release.zh-CN.md)。

## 本次变化

- 安装前集中检查 Python、Node.js、npm 与源码完整性，避免下载到一半才发现缺少 Node.js。
- 成功步骤分别记录并校验。重复运行复用依赖和生产构建；依赖、源码、前端环境变化或产物不完整时重新执行受影响步骤。
- 每次安装提供独立日志；失败后可继续，多个安装进程不会同时修改环境。
- 增加 `setup.bat --check` 与 `--repair`。MongoDB 尚未就绪时保留依赖和构建，返回清楚的后续操作。
- 双击启动后等待后端就绪，再启动前端；两者健康检查通过后自动打开工作台。`start.bat --manual` 保留手动模式。
- 同一启动器避免连续点击重复启动和开页；停止或关闭会取消后续步骤，并清理取消时刚创建的自有进程。

本包也收录 `main` 已合入的弃稿调用恢复、Windows 证书兼容、生成 Token 上限缺失提示，以及自动成书暂停后的定位和世界资料复核改进。暂停处理见[使用指南](../user-guide.zh-CN.md#自动成书)，保留限制见[已知局限](../known-limitations.zh-CN.md)。

## 验证与范围

安装、重复运行、只检查、失败恢复、缓存失效、超时和取消有自动回归；在独立目录进行实际安装、实际服务启动与完整非付费验证，安装检查方式见[排错指南](../troubleshooting.zh-CN.md)。

仍为需要 Python、Node.js、MongoDB 和首次联网安装的源码包，未捆绑运行环境。既有 [rc.1](0.1.0-rc.1.zh-CN.md) 功能与付费授权边界保持；本轮不调用真实 Provider。该候选归档生成于本项目加入 AGPL-3.0 许可证之前，保留私有评审标记；当前源码的[许可证与来源](../license-status.zh-CN.md)另有明确说明。
