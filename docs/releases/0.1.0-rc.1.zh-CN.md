# Novel-G 0.1.0-rc.1

2026-09-11 私有源码评审候选。该归档生成时尚未加入项目许可证，归档内容与校验值保留原样；当前源码已采用 AGPL-3.0，见[许可证与来源](../license-status.zh-CN.md)。完整安装步骤见 [源码包说明](../source-release.zh-CN.md)。

## 包含的能力

- 本地账号、书架、世界资料、卷章大纲、自动保存与本地草稿恢复。
- 从创意、蓝图到正文和状态回写的写作链路，及显式授权下的整卷、整本生成。
- 资料卡互操作、状态证据复核、可恢复候选和生成进度诊断。
- 可选的角色画像、封面与场景插图，支持已实现的图像 API 和 ComfyUI 接入路径。

## 本轮稳定性与发布准备

修复了保存响应覆盖较新草稿、保存失败后仍继续状态回填、势力旧编号复用、跨集合备份不一致、空值更新、备份回退生成授权、建章与删卷竞态、受限浏览器存储崩溃，以及回收站重开后漏项。

依赖安全更新包括 Next.js / eslint-config-next 16.3.4、sharp 0.35.4、FastAPI 0.136.3、Starlette 1.3.1、python-multipart 0.0.32、pytest 9.0.3 与 cryptography 50.0.1；前端间接依赖通过 lockfile 更新到修复版本。Node.js 最低支持调整为 22.13，安装器更新 pip 至 26.2.1。

源码包从冻结提交生成，附文件清单和 ZIP 校验值。全库验证、依赖扫描、合成数据浏览器回归及当前源码凭据扫描已加入 CI。安装与日常检查见[排错指南](../troubleshooting.zh-CN.md)。

## 使用边界

这是面向可信本机 / 局域网的候选版本，未做公网托管服务验收。首次安装需要自行安装运行环境并联网获取依赖。恢复备份会作废旧作业授权，继续生成需要重新预检；活跃或用量未确认的任务会阻止恢复。

本轮发行验证不触发真实付费 Provider 调用。模型及图像提供商存在独立的配置、协议和输出差异，既有验收记录不保证任意自定义端点可用。已知局限见 [使用范围与已知局限](../known-limitations.zh-CN.md)。

Git 历史中的旧凭据记录仍需在公开仓库前妥善处理；本包不含 Git 历史或本机秘密配置。来源与许可证据见 [第三方与上游说明](../third-party-notices.zh-CN.md)。
