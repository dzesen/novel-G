# Novel-G 0.1.0-rc.3

2026-09-11 私有源码评审候选。本轮整理安装包和对外源码导出的内容范围，安装及启动方式沿用 rc.2。

## 本次变化

- 按明确清单收录应用源码、固定依赖、安装启动入口和用户文档。
- 排除内部规格、过程记录、排查与模型验收材料，以及开发测试、夹具和一次性工具。
- 保留生产代码实际依赖的模块，提供商配置检查等运行能力不受文件名中 test 字样影响。
- ZIP 与 Git 源码导出采用一致规则；新增内部文档默认不进入包内。
- 打包时检查用户文档链接，阻止指向未收录文件的链接。文件清单不展示被排除的内部文件名。
- 安装检查统一使用 `setup.bat --check`；完整回归测试继续在私有开发库和 CI 中执行。
