# 使用范围与已知局限

本页说明当前功能边界与处理方式。

## 安装与部署

当前提供 Windows 源码安装包，需要自行安装 Python、Node.js 和 MongoDB，首次安装需要联网下载依赖。尚未提供捆绑全部运行环境的离线便携包。

默认面向可信本机使用，可主动启用可信局域网模式。公网托管和多租户服务部署尚未验收。现有归档仍为私有评审候选；当前源码采用 AGPL-3.0，项目来源及旧归档范围见[许可说明](license-status.zh-CN.md)。

## 自动成书与模型表现

自动成书在确认的范围、调用次数和预算内推进，无法保证任意题材、模型或长篇任务均无需人工介入。整本长期吞吐、模型审查准确率和跨提供商稳定性仍缺少充分验收。

长章节可能按场景发起多次模型请求。预检中的调用与 Token 上界是授权约束，不是对实际耗时、输出质量或最终账单的承诺。提供商自身的输出能力、结构化协议、超时及计费方式仍需在配置时核对。

截断或场景不完整的草稿只能显式恢复或作为部分结果处理，不能自动算作完整章节。正文保存与状态回填分别记录，单章作者确认保存本身不代表整书完成。

## 审查与恢复

独立模型审查可能误判或无法形成有效结论。建议模式供作者参考，严格模式可以阻止完成。未审查和审查未完成都会保留其实际状态，不会伪装为通过；作者应结合原文与证据判断。

断网或进程中断可能留下尚未确认用量的请求，需要在恢复入口处理。恢复作业不会增加原授权额度；扩大范围或预算需要新的预检。恢复全库备份会使旧生成授权失效。

## 世界资料与互操作

安全自动建卡只适用于已经授权、通过确定性校验的唯一全新资料；当前每章最多 3 个、整本累计最多 20 个。合并、恢复合并和身份歧义仍需人工处理，新资料变化也可能要求重新确认世界资料基线。

酒馆卡支持经审核的 JSON、PNG 元数据和世界书导入。暂不支持 CHARX、角色卡 PNG 导出、头像或媒体附件导入，以及 `.jsonl` 聊天记录转小说。Character Card V2 JSON 导出暂由后端端点提供，尚无专用界面。自由文本世界书的自动分类可能回退为世界设定，需要作者复核。

## 图像与本地文件

图像 API 与 ComfyUI 的协议、节点和资源配置存在差异，已有接入路径不保证任意自定义工作流可用。插图是可选资产，不决定正文或成书完成。

全库数据库备份不包含本机配置和图片文件。迁移、升级或恢复前，应另外保留配置与文件资产。

具体操作见[使用指南](user-guide.zh-CN.md)，遇到故障见[排错指南](troubleshooting.zh-CN.md)。
